# Common Language Endonyms Reference

When adding a language to `_locale-switcher.twig`, always use the language's native **endonym** (its name in its own language) rather than translating it into English or the default locale.

| Code | English Name | Native Endonym |
| :--- | :--- | :--- |
| `cs` | Czech | **Čeština** |
| `sk` | Slovak | **Slovenčina** |
| `en` | English | **English** |
| `de` | German | **Deutsch** |
| `fr` | French | **Français** |
| `pl` | Polish | **Polski** |
| `es` | Spanish | **Español** |
| `it` | Italian | **Italiano** |
| `nl` | Dutch | **Nederlands** |
| `hu` | Hungarian | **Magyar** |
| `uk` | Ukrainian | **Українська** |
| `ru` | Russian | **Русский** |
| `pt` | Portuguese | **Português** |
| `da` | Danish | **Dansk** |
| `sv` | Swedish | **Svenska** |
| `no` | Norwegian | **Norsk** |
| `fi` | Finnish | **Suomi** |
